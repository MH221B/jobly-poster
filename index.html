Nền tảng
Thực trạng
  • Sinh viên mới ra trường gặp khó khăn khi tối ưu hồ sơ (CV) và định hướng nghề nghiệp.
  • Nhà tuyển dụng quá tải với hàng nghìn hồ sơ, đánh giá cảm tính, lãng phí nguồn lực.
  • Các nền tảng hiện tại vận hành khép kín, thiếu tương tác động, chưa cá nhân hóa sâu.
Mục tiêu
  • Xây dựng JoblyAI trên đa nền tảng Web và Mobile.
  • Ứng dụng LLM và NLP làm "chuyên gia nhân sự ảo".
  • Phát triển 6 tính năng AI: trích xuất CV, chấm điểm hồ sơ, đề xuất việc làm, sinh câu hỏi sàng lọc, đánh giá câu trả lời, sinh câu hỏi phỏng vấn.
  • Tích hợp MCP cho phép AI Agent bên ngoài thao tác qua 21 công cụ chuẩn hóa.
Vì sao JoblyAI? (1) Hệ thống mở - không khép kín như các nền tảng truyền thống. (2) AI mạnh - 5 tính năng AI cốt lõi dùng Gemini + RAG. (3) Đa nền tảng - Web (Next.js) + Mobile (React Native/Expo) cho cả 2 nhóm đối tượng.

Công nghệ & Tái sử dụng
Frontend
  • Next.js 16 (App Router, RSC, Server Actions)
  • Tailwind CSS 3.4 + Mantine v9 + Radix UI
  • TanStack Query + React Hook Form + Zod
  • React Native (Expo SDK 54) + NativeWind
  • Recharts, Sonner, pdfjs-dist, markdown-it
Backend
  • NestJS + Prisma ORM + REST API (Swagger)
  • Socket.IO (3 gateway: chat, notify, AI stream)
  • Better-Auth (session cookie) + Google OAuth 2.0
  • BullMQ + Worker pattern cho tác vụ nền async

Cơ sở dữ liệu
  • PostgreSQL 17 + pgvector (embedding 768d)
  • ScyllaDB (chat real-time, tham khảo Discord)
  • Redis (BullMQ + session + pub/sub)
  • Google Cloud Storage (2 bucket: private/public)
  • Prisma migration qua Cloud SQL Auth Proxy
AI & DevOps
  • Google Gemini 3.5 Flash (text) + Gemini Embedding 2 (vector 768d)
  • RAG + Google Search grounding
  • MCP Server (stateless, 21 tools, Streamable HTTP)
  • GCP Cloud Run + Artifact Registry + Docker
  • GitHub Actions CI/CD (5 bước: xác thực GCP → build Docker → push Artifact Registry → deploy Cloud Run → migration Prisma)

Khó khăn & Khắc phục
Khó khănKhắc phục
Độ chính xác AI phụ thuộc Gemini API, đôi khi "ảo giác" (hallucination) và JSON lỗi. Thêm Chain-of-Thought, responseMimeType: 'application/json', validate bằng Zod, retry tối đa 2 lần với exponential backoff (cv-matching-score pipeline retry 3 lần).
Split-view diff/merge CV phức tạp, nhiều vòng lặp Figma để đạt trải nghiệm mượt mà. Tái thiết kế với 2 cột song song, highlight màu cho field khác biệt, dùng Prisma transaction để commit merge an toàn.
Mobile responsive chưa tối ưu trên màn hình nhỏ, ATS bar chiếm nhiều diện tích. Tinh chỉnh kích thước chữ và khoảng cách đệm (padding) trên bảng điểm AI chi tiết và thanh ATS, đảm bảo không bị tràn giao diện.
FE/BE data type mismatch khi thay đổi schema, dẫn đến runtime errors khó debug. DTO manual sync giữa BE và FE qua Pull Request review.
Thiếu thiết bị di động thực tế thế hệ mới, phải phụ thuộc vào máy ảo. Mở MCP server qua Streamable HTTP để bên thứ ba tích hợp, ủy quyền cho Agent tự động hoá quy trình.
Chi phí hạ tầng đám mây có hạn, gói miễn phí/giá rẻ gặp khó khăn khi nhiều tác vụ chạy đồng thời. Tối ưu bằng cách thiết lập lịch chạy CI/CD so le và tinh chỉnh kích thước vùng chứa Docker.

MCP Tools
  • Mạng công cộng: Browser (Next.js) + Mobile (Expo) → Cloud Load Balancing & Cloud DNS.
  • Tầng ứng dụng (Cloud Run): Frontend Next.js (BFF + SSR) + Backend NestJS (REST + 3 WebSocket gateway + MCP server).
  • Tầng dữ liệu: Cloud SQL PostgreSQL 17 + pgvector · VM chạy Redis (BullMQ) + ScyllaDB (chat) · GCS 2 bucket.
  • CI/CD: GitHub Actions → Artifact Registry → Cloud Run với Secret Manager + Prisma migration qua Cloud SQL Auth Proxy.
  • AI: Google Gemini 3.5 Flash (text) + Gemini Embedding 2 (vector 768d) qua AiProviderService, ứng dụng cho 6 tính năng thông minh.
  • Serverless scaling: Tự động scale 1-5 instances, concurrency 80 req/s, timeout 3600s cho AI pipeline.

Điểm mạnh & Bài học kinh nghiệm
  • Kiến trúc Monorepo với Nx quản lý đa dự án đồng nhất, hỗ trợ mở rộng cả chiều ngang và chiều dọc.
  • CI/CD tự động hoá toàn bộ (5 giai đoạn: xác thực GCP → build Docker → push Artifact Registry → deploy Cloud Run → migration Prisma).
  • Kiểm thử backend với Vitest, API docs tự động (Swagger).
  • Split-view UI cho merge CV qua nhiều vòng lặp Figma mới đạt.
  • Async pipeline (BullMQ) + Socket.IO real-time cho AI tasks tránh timeout.
  • Quy trình 6 bước: yêu cầu → thiết kế → API + types → code → Swagger → PR review.
Hạn chế
  • Hướng dẫn sử dụng chưa đủ trực quan, thiếu quy trình onboarding cho người dùng mới.
  • Cần tối ưu hiệu năng khi mở rộng quy mô lớn hơn.
  • Độ chính xác AI phụ thuộc Gemini API, hallucination & lỗi JSON đôi khi vẫn xảy ra.
  • Mobile AI features (Interview Prep, Pre-shortlist) chỉ có trên Web.
  • Chưa tích hợp với LinkedIn / VietnamWorks / TopCV.
  • Giao diện di động: bảng điểm AI chi tiết chưa tối ưu trên màn hình nhỏ.
Làm việc nhóm: Chia 6 vai trò rõ ràng (Project Leader, Backend, FE Web, Mobile, AI Engineer, DevOps Engineer), mỗi tuần họp 3 buổi (nội bộ + advisor + tích hợp), mỗi sprint 1 tuần tối thiểu 5 SP, review PR chéo giữa ≥ 2 thành viên, quy ước commit & branch rõ ràng.
Kết quả: 6 vòng PR review, coverage threshold cho Auth (100%) và các module core (≥ 80%), tích hợp liên tục qua GitHub Actions CI/CD.
